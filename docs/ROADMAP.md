# Roadmap — Caderno de Libras

> Visão do que pode vir depois. **Não é compromisso de prazo**: cada item passa pelo plano →
> OK do André → código. A ordem real sai do levantamento de requisitos (`docs/REQUISITOS.md`).

## Princípios
- Feito para ela estudar: simples, rápido no celular, sem anúncios.
- Sinais nunca inventados pelo app; conteúdo de terceiros só como link (ver `CLAUDE.md`).
- Dados dela são dela (LGPD): fotos, vídeos e anotações privados por padrão.

## Ideias (vindas do protótipo e do questionário)
- [ ] Caderno de sinais com os 5 parâmetros (protótipo já tem).
- [ ] Revisão com repetição espaçada (protótipo já tem).
- [ ] Treino de datilologia (protótipo já tem).
- [ ] Foto ou vídeo do sinal (Supabase Storage privado).
- [ ] Gravar a si mesma e comparar.
- [ ] Quiz com vídeo.
- [ ] Números, datas e horas.
- [ ] Frases prontas do dia a dia.
- [ ] Lembrete de estudo e sequência de dias.
- [ ] App instalável e offline (PWA).
- [ ] Compartilhar sinais com a turma.
- [ ] Importar os sinais anotados no protótipo.
